# GigaAM Desktop для Windows и Linux

Сборки предназначены для компьютеров x64. Модели GigaAM, Silero, WeSpeaker и pyannote Community-1 входят в дистрибутивы. При выборе **Распознать → Диаризация + протокол** голоса системной дорожки получают метки участников, микрофон получает метку «Я». Для отдельного аудиофайла выберите **Распознать с диаризацией**. Дополнительный локальный сервис Ollama нужен для создания протокола.

На Windows установите приложение и откройте GigaAM Desktop из меню «Пуск». Приложение использует WebView2 и WASAPI. На Linux установите пакет командой `sudo apt install ./имя-пакета.deb`. Пакет для Ubuntu 24.04 x86-64 использует WebKitGTK и FFmpeg из репозитория дистрибутива. Для записи нужен работающий PulseAudio или PipeWire с поддержкой PulseAudio. Системная дорожка записывается с текущего устройства вывода.

Манифест `sidecar/desktop-release.json` содержит версии и контрольные суммы CPython, CPU-сборок PyTorch и общих ресурсов. При сборке `scripts/stage-desktop-runtime.py` разворачивает окружение в каталоге ресурсов, запускает распознавание на открытых тестовых записях и проверяет метки говорящих. В архиве общих компонентов содержатся лицензии моделей и параметры сборки FFmpeg для Windows. [Модели и авторство](MACOS_OFFLINE.md#models-and-attribution)
